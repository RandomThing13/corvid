Corvid demo guide

Source-backed answers for the Stoa challenge.

Open Corvid. Download a sample below, then upload it using the existing file chooser. Select its page and paste a question. Click the linked source labels, room boundary and graphic scale to inspect the evidence.

Shared demonstration service

Uploads are processed on a shared hackathon demonstration service. Use these public examples rather than confidential plans. This bounded method does not establish general drawing accuracy. Whole-floor classification can remain unresolved.
